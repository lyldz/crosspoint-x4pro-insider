- Her gün 19:00'da (Türkiye saati) çalışır; upstream'de yeni commit yoksa derlemez.
- Sonuç: [Releases → insider](https://github.com/lyldz/crosspoint-x4pro-insider/releases/tag/insider)
- Sabit indirme linki: https://github.com/lyldz/crosspoint-x4pro-insider/releases/download/insider/firmware.bin
- Elle çalıştırma: Actions → "Crosspoint X4 Pro insider build" → Run workflow

Bu bin yalnızca X4 Pro içindir. X4, X3 veya X4C cihazlara yüklemeyin. Resmi bir derleme değildir.
